# Changelog

## 1.0.0

The first release of Porto Faifo, 26 November 2026. Porto Faifo is the new name of KÉT Sans,
KÉT Sans Mono and Két Symbol; the letterforms are those of KÉT Sans 1.1 and KÉT Sans Mono 0.10.4.

- **Porto Faifo Sans**: Light, Regular, Medium, Bold, Black; optical-size and variable fonts.
- **Porto Faifo Mono**: Regular, Medium.
- **Porto Faifo Symbols**: 322 symbols at 14, 16, 20 and 24 px in four weights, as SVG files and sprites.
- File names start with `PF`; sprite ids start with `pf-`.

| Package | Contents |
| --- | --- |
| `PFSans-1.0.0.zip` | OTF, TTF, WOFF2, optical-size and variable fonts |
| `PFMono-1.0.0.zip` | OTF, TTF, WOFF2 |
| `PFSymbols-1.0.0.zip` | SVG files, sprites, manifest, preview page |
